# kyfromabove-stac-addin

ArcGIS Pro add-in for searching and downloading Kentucky From Above STAC imagery, DEM, and LiDAR
point cloud data.

## Documentation

Full docs (installation, getting started, area of interest, downloads, and more) live in
[`docs/`](docs/index.md), built with [MkDocs](https://www.mkdocs.org/) and the
[Material theme](https://squidfunk.github.io/mkdocs-material/).

To preview locally:

```bash
pip install -r docs-requirements.txt
mkdocs serve
```

Then open <http://127.0.0.1:8000>.
